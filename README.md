# 🏛️ Learning Corner – Museum Booking System (PHP + MySQL)

This project is a simple **web-based learning corner** for a museum website, developed using **PHP**, **MySQL**, **HTML**, **CSS**, and **JavaScript**. It allows visitors to explore available **workshops** and **guided tours**, and book a spot for educational experiences at the museum.

---

### ✨ Features:
- 📅 View available **workshops** and **tours**
- 📝 **Booking form** to register for an event
- 💾 Store user reservations in a **MySQL database**
- 📤 Confirmation message upon successful booking
- 🎨 Simple and clean user interface with responsive design

---

### 🛠️ Technologies Used:
- **Frontend**:
  - HTML5
  - CSS3
  - JavaScript
- **Backend**:
  - PHP (for server-side logic and form processing)
  - MySQL (for storing workshop/tour data and bookings)
